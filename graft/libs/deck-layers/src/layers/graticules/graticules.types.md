- GraticuleLineGroup · type · L5-L5 — Enumeration of valid graticule line spacing intervals in degrees for rendering geographic grids.
- GraticulesLayerProps · type · L7-L10 — Configuration schema for graticule layer rendering with color and thickness styling options.
- ViewportSize · type · L12-L15 — Structure defining the rectangular dimensions of a rendering viewport.
- GraticulesLayerState · type · L17-L20 — Internal state container tracking viewport identity and cached graticule line feature geometry.
- GraticulesProperties · type · L22-L26 — Metadata attributes attached to individual graticule lines indicating hierarchy, labels, and orientation.
- GraticulesFeature · type · L28-L28 — GeoJSON feature binding graticule line geometry with geographic grid metadata properties.
