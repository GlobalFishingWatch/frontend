# libs/ui-components/src/thickness-selector/thickness-selector-options.ts · [[thickness-selector]]

Configuration module that defines thickness selector options with type definitions and a preset list of thickness levels.

- Thicknes · type · L1-L1 — Union type that constrains thickness values to three discrete levels: thin, medium, or thick.
- ThicknessSelectorOption · type · L2-L5 — Data structure that pairs a thickness category identifier with its corresponding numeric value.
