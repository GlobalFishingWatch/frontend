# libs/api-types/src/fourwings.ts · [[api-types-type-definitions]]

Type definitions for Fourwings heatmap and events interactions in the API.

- FourwingsHeatmapInteraction · type · L1-L3 — Defines the minimal heatmap interaction interface with an identifier.
- FourwingsEventsInteraction · type · L5-L11 — Defines the events interaction interface with event count and optional port metadata.
- FourwingsInteraction · type · L13-L13 — Union type representing either a heatmap or events interaction.
