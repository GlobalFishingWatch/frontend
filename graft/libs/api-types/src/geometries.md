# libs/api-types/src/geometries.ts · [[api-types-type-definitions]] [[geospatial-filtering-region-hierarchies]]

File containing shared type definitions for GeoJSON-based tile context area features used across the API.

- TileContextAreaFeatureProperties · type · L3-L6 — Type defining the properties object structure for a tile context area feature, requiring a GeoFW ID and allowing arbitrary string key-value pairs.
- TileContextAreaFeature · type · L8-L18 — Generic type defining the complete structure of a GeoJSON-like feature for tile context areas, with customizable geometry and property types.
