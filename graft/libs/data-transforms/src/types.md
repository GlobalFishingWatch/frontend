# libs/data-transforms/src/types.ts · [[data-types-and-type-contracts]]

Type definitions module for dataset transformation structures including bounding boxes, segment columns, and point columns.

- Bbox · type · L3-L3 — Represents a bounding box as a tuple of four numbers for geographic coordinates.
- SegmentColumns · type · L5-L13 — Defines the required and optional columns for a line segment with geospatial coordinates and temporal metadata.
- PointColumns · type · L15-L22 — Defines the required and optional columns for a geospatial point with temporal range and dataset filters.
