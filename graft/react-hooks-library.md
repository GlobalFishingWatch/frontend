## Summary

Collection of fourteen reusable React hooks for analytics, authentication, storage, DOM interactions, and responsive design. Each hook is implemented in its own module with a barrel export pattern, enabling fine-grained imports without loading the entire library.

## Related

- implements [[react-hooks-authentication-flow]] — useGFWLogin, useGFWLoginRedirect, useLoginRedirect, and Login component orchestrate token extraction, session management, and protected content rendering
- implements [[react-hooks-lazy-analytics]] — useAnalyticsInit and trackEvent provide lazy-loaded GA4 integration with singleton pattern and snake_case parameter formatting
- implements [[react-hooks-responsive-behavior]] — useSmallScreen, usePageVisibility, useNavigatorOnline, and usePrintSize enable responsive UI adapting to viewport, page state, and connectivity changes
- depends on [[react-hooks-standard-library-dependencies]] — Hooks delegate to external libraries: es-toolkit for debounce/isEqual/snakeCase, usehooks-ts for storage, react-ga4 for analytics, @globalfishingwatch/api-client for auth
- implements [[react-hooks-state-and-refs-management]] — useMemoCompare, useStateCallback, usePrevious, and useTrackDependencyChanges provide state comparison, delayed callbacks, and debugging utilities
