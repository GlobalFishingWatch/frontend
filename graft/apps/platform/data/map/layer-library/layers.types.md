# apps/platform/data/map/layer-library/layers.types.ts · [[dataview-instance-management]] [[layer-library-system]] [[localization-and-resource-keys]]

Type definitions for layer library configuration and metadata used by the map platform.

- LayerLibraryId · type · L14-L14 — Constrains layer identifiers to keys available in the i18n layer-library resource bundle.
- LibraryLayerConfig · type · L15-L20 — Extends a dataview instance with library-specific metadata including preview imagery and optional access restrictions.
- LibraryLayer · type · L22-L27 — Merges library configuration with runtime dataview context including category, dataset configuration, and resolved preview image.
