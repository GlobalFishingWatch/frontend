# apps/platform/features/cms/loaders/data-update.types.ts · [[cms-content-management]]

Defines the TypeScript type contracts for CMS data update content and individual update records with metadata fields.

- DataUpdateContent · type · L3-L3 — Represents a collection of data update records returned from CMS loaders.
- DataUpdate · type · L5-L11 — Defines the structure of a single CMS data update with title, slug, optional thumbnail and body content, and publication date.
