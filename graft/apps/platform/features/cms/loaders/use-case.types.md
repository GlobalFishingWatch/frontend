# apps/platform/features/cms/loaders/use-case.types.ts · [[cms-content-management]]

Type definitions for use-case content organization, including role classifications and section structures for CMS-driven content.

- UseCaseSectionSlug · type · L15-L15 — Type representing the valid section slug keys derived from the use case roles configuration.
- UseCaseRole · type · L17-L17 — Type representing the display label string for a use case role based on the configuration mapping.
- UseCaseContent · type · L19-L19 — Type representing a collection of use case sections forming the complete content structure.
- UseCaseSection · type · L21-L27 — Type defining the structure of a use case section with role, slug, optional thumbnail image, body text, and nested subsections.
- UseCaseSubSection · type · L29-L33 — Type defining the structure of a subsection within a use case, containing title, body text, and a slug identifier.
