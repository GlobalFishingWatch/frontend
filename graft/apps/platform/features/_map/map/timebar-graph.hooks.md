# apps/platform/features/_map/map/timebar-graph.hooks.ts

Provides React hooks for computing and retrieving vessel track graph extent and visualization steps for timebar graphs.

- useTimebarTracksGraphExtent · function · L13-L35 — Computes the clamped extent (min/max bounds) of vessel track graph data across all loaded vessels based on the selected graph type.
- useTimebarTracksGraphSteps · function · L37-L49 — Generates visualization steps for vessel graph data when the graph type is speed or elevation.
