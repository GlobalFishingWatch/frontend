# apps/platform/features/i18n/i18nFlag.tsx · [[internationalization]]

Module that provides i18n support for displaying localized flag names based on ISO country codes.

- useI18nFlag · function · L6-L9 — Hook that translates an ISO country code to its localized flag name using the i18next translation system.
- I18nFlag · function · L11-L14 — React component that renders a localized flag name for a given ISO country code, with a fallback placeholder for empty values.
