Configuration file for i18n (internationalization) settings, namespaces, supported languages, and language resolution utilities for the platform.

- resolveLanguageFromSources · function · L79-L100 — Determines the active language by checking sources in priority order: URL query parameter, cookie, HTTP Accept-Language header, then English fallback.
- toContentLocale · function · L116-L122 — Converts an i18n language code to a real Locale enum value, mapping development preview codes to English for content rendering.
- toDocumentLang · function · L124-L126 — Maps an i18n language to the HTML document language attribute by delegating to content locale resolution.
