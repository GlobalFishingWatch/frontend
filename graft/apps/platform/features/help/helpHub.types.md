# apps/platform/features/help/helpHub.types.ts · [[help-hub-system]]

Defines the type contracts for the Help Hub feature, including sections, items, and their subsections.

- HelpHubSection · type · L4-L4 — Extracted union type representing a single help hub section from the configuration array.
- HelpHubSectionId · type · L5-L5 — Extracts the id property type from a help hub section for type-safe section identification.
- HelpHubSectionSlug · type · L6-L6 — Extracts the slug property type from a help hub section for type-safe URL routing.
- HelpHubItemSubsection · type · L8-L13 — Defines the structure for nested subsections within help hub items with optional metadata.
- HelpHubItem · type · L15-L24 — Defines the complete structure for a help hub article item with content, metadata, and nested subsections.
