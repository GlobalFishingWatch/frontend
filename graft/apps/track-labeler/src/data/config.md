Configuration module for the track labeler application, exporting constants and types for basemap settings, track fields, viewport defaults, contextual layers, and workspace state.

- ContextualLayerTypes · type · L42-L50 — Type alias enumerating the internal layer type identifiers used in the mapping system for various contextual features.
- TimebarMode · enum · L59-L63 — Enumeration defining the three visualization modes for the timebar: speed, hours, and bathymetry.
